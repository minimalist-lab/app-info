プライバシーポリシー

最終更新日：2026年9月8日

1. 取得する情報

本アプリは、独自のアカウント登録を必要とせず、運営者の外部サーバーへの個人情報の送信を行いません。

詳細な学習記録、仕訳データ、ドリル履歴の保存データは、以下のいずれかにのみ保存されます。

  • お使いの端末内（アプリのサンドボックス領域）
  • ご利用の Apple ID に紐づく iCloud Drive（iCloud が有効な場合のみ）

2. iCloud 同期について

iCloud が有効な端末では、学習データが自動的に iCloud Drive に保存されます。これは同じ Apple ID の他のデバイスと同期するためで、データは Apple のインフラに暗号化された状態で保管されます。本アプリの運営者はこのデータを参照できません。

iCloud を利用したくない場合は、iOS の「設定 > Apple ID > iCloud > iCloud Drive」から Boki Lens をオフにしてください。この場合、データは端末内のみに保存されます。

3. 課金（App内課金）

プレミアム購入の処理は Apple の App Store 経由で行われます。本アプリ自体は購入者の決済情報を取得・保存しません。

4. 解析・広告

本アプリは、画面や機能の使われ方、学習の進み方、購入までの流れを把握してアプリを改善するために、プライバシー重視の解析サービス TelemetryDeck (TelemetryDeck GmbH) を利用します。

バージョンによる共有設定の違い

1.14：以下の匿名イベントを、アプリ内での共有許可の選択なしに送信します。この版には「任意の利用状況共有」の設定はありません。

1.15以降：利用状況の共有は任意です。初回案内または「設定 > 任意の利用状況共有」で明示的に許可した場合のみ送信します。許可する前や「共有しない」を選んだ場合は、イベントを送信せず、送信用の匿名 ID も作成しません。同意前のイベントは、後で送信するために保存することもありません。1.14から更新し、共有を許可した記録がない場合も、許可するまで送信しません。共有しなくても、学習・購入・購入の復元を含むすべての機能を同じように利用できます。この説明は1.15以降をインストールした端末に適用され、1.14の動作を変更するものではありません。

送信する情報

送信するのは、端末内でランダムに生成した ID のハッシュ、解析セッションごとのランダムな ID、アプリのバージョンとビルド番号、テスト用イベントかどうかの区分、および画面・機能・学習進捗・購入成功を表す操作イベントです。

以下の情報は TelemetryDeck に送信しません。

  • 仕訳の内容、入力した金額、自由入力の内容
  • 名前、メールアドレスなどの連絡先
  • 広告・トラッキング目的の識別子

学習進捗イベントには、ステージ ID、レッスン ID、学習を開始した入口の分類、解いた問題数、正答数などが含まれる場合があります。各イベントの共通情報として、表示言語（日本語または英語）、利用者が選んだ学習トラック（未選択、日本の簿記、または Global Basics）、教材体験の版が含まれる場合があります。端末の地域、国、未加工のロケール情報は送信しません。購入成功イベントには、プラン名、商品 ID、購入を開始した画面・機能の分類が含まれる場合があります。この分類はステージ、ドリル、シナリオ、設定、または不明のいずれかで、画面文言、取引 ID、価格、Apple ID は含みません。広告 SDK は使用していません。解析データは利用者個人と紐づけられず、広告やトラッキングには使用しません。

1.15以降で共有をやめる場合

「設定 > 任意の利用状況共有」からいつでも撤回できます。撤回すると今後の送信を停止し、端末内の未送信イベントの削除を行います。ファイルの削除に失敗した場合も、そのイベントを無効化して再送を防ぎます。端末内の匿名 ID も削除します。後で再び許可すると、新しいランダムな匿名 ID を作成します。この操作で学習記録、仕訳、iCloudの保存データは削除されません。

5. データの削除と解析データの保持

  • 端末からアプリを削除すると、端末内に保存されたデータは消去されます。
  • iCloud Drive 上のデータは残ります。完全に削除したい場合は、iOS の「設定 > Apple ID > iCloud > ストレージを管理 > Boki Lens」から「データを削除」を選択してください。
  • 解析の共有撤回やアプリの削除を行っても、TelemetryDeckへ送信済みのイベントは削除されません。本アプリでは、送信済みの匿名イベントを利用者本人に紐づけられないため、利用者ごとの削除には対応できません。

TelemetryDeckは、長期保管（コールドストレージ）のイベントについて、現在は削除スケジュールを定めておらず、保存期限を保証していないと説明しています。最新の条件はTelemetryDeck Privacy FAQの保存期間に関する説明をご確認ください。これは解析サービスへ送信済みのイベントの扱いであり、端末やiCloudに保存する学習データの削除手順とは別です。
